# SGEstética

PROMPT MESTRE — SISTEMA SAAS PARA CLÍNICAS DE ESTÉTICA

Quero criar uma aplicação web SaaS premium, moderna, responsiva e escalável para gestão completa de clínicas de estética.

O sistema deve ser inspirado nas melhores funcionalidades de plataformas como Belle Software, porém NÃO deve ser uma cópia visual ou funcional.

A proposta é criar uma experiência superior, mais moderna, simples, intuitiva e fortemente baseada em automações e inteligência artificial.

O produto futuramente deverá atender centenas ou milhares de clínicas diferentes.

Portanto, desde o início, construa a aplicação com arquitetura multi-tenant.

O nome do sistema é SG Estética
